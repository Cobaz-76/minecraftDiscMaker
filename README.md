# Custom Disc Maker
This is a python application for generating a data pack and resource pack that add custom music discs to Minecraft.
Use the GUI to input disc names, texture paths, and sound paths, and output a data and resource packs to add those discs to Minecraft.

Features:
 - Supports animated disc textures. (You make these by stacking the frames on top of each other in the png file
 - Preview animated textures in the GUI! (Please use this. I spent so long making it work.)
 - Adds the custom discs to the creeper-killed-by-skeleton loot table
